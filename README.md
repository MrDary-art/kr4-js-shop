# Флора

Статический интерфейс магазина и Go-бэкенд без внешних зависимостей.

## Запуск

```powershell
go run .
```

После запуска сайт доступен по адресу `http://localhost:8080`.

API:

- `GET /api/health` — проверка сервера;
- `GET /api/products` — краткий каталог;
- `POST /api/orders` — проверка и регистрация заказа из формы.

Проверка бэкенда:

```powershell
go test ./...
```
