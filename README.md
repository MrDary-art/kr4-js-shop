# Флора — интерактивный цветочный магазин

Профессиональный многостраничный storefront на чистом HTML, CSS и JavaScript. Проект закрывает требования практик №12–14: адаптивность, доступность, DOM, события, поиск, фильтры, сортировка, валидация и состояние в `localStorage`.

## Возможности

- шесть полноценных страниц: главная, каталог, карточка товара, корзина, оформление и контакты;
- каталог из 12 букетов, создаваемый безопасно через `createElement`, `textContent`, `classList` и `append`;
- поиск, фильтры, сортировка, счётчик результатов и empty-state;
- быстрый просмотр в нативном `dialog`;
- корзина, избранное, изменение количества, итоговый расчёт и промокод `FLORA10`;
- валидация формы на `blur`, `change` и `submit` с inline-ошибками без `alert()`;
- закреплённая liquid-glass шапка, четыре основных раздела, мобильное меню и полноценный футер;
- две адаптивные типографические роли, объёмные цветочные вырезки и деликатная motion-система.

## Практики 12–14

### №12. Адаптивная вёрстка

- mobile-first CSS и отдельный `css/responsive.css`;
- контрольные ширины 360–1440 px;
- адаптивные header, hero, каталог, фильтры, карточки, формы и футер;
- фиксированные `width`/`height` у изображений и `loading="lazy"` для некритических фото.

### №13. Доступность

- семантические landmarks, один `h1` на страницу, осмысленные `alt` и подписи полей;
- skip-link, заметный `:focus-visible`, клавиатурное закрытие меню и диалога;
- live regions для корзины, результатов, toast и ошибок;
- `prefers-reduced-motion`, `prefers-reduced-transparency` и `prefers-contrast`;
- axe-core WCAG 2.1 A/AA: 0 нарушений на шести страницах, отчёт — `audit/accessibility.json`.

### №14. JavaScript, DOM, события и формы

- `js/data.js` — массив из 12 товаров;
- `js/render.js` — безопасный DOM-рендер;
- `js/filters.js` — поиск, фильтры и сортировка;
- `js/store.js` — корзина, избранное и промокод;
- `js/form.js` — валидация;
- `js/main.js` — инициализация, события и motion;
- все обработчики подключены через `addEventListener`, данные выводятся через `textContent`.

## Запуск

Проект использует ES-модули, поэтому его нужно открывать через HTTP-сервер:

```powershell
py -3 -m http.server 4173
```

Затем откройте `http://127.0.0.1:4173/index.html`.

## Проверки

```powershell
node --check js/main.js
node scripts/audit-a11y.mjs
node scripts/test-shop.mjs
```

Сквозной тест проверяет 8 сценариев. Актуальный резуль хранится в `audit/functional.json`.

## Структура

```text
css/                 базовые стили и адаптивные breakpoint-ы
images/              каталожные, hero- и review-изображения
js/                  данные, DOM-рендер, фильтры, состояние и формы
scripts/             автоматизированные аудиты
audit/               JSON-отчёты аудитов
PRODUCT.md           продуктовые ограничения
DESIGN.md            дизайн-система и токены
```

## Изображения и честность контента

Прозрачные bouquet-объекты, 12 каталожных кадров и три review-сцены созданы для этого проекта с помощью OpenAI ImageGen. Атмосферные фотографии на главной странице взяты с Unsplash; авторы и прямые ссылки указаны в футере `index.html`.
